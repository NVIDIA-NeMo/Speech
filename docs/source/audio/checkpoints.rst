Checkpoints
===========

The denoising and dereverberation checkpoints below process recordings directly; see :doc:`Inference and Evaluation
<./inference>`. The flow matching checkpoint was pretrained with self-supervised masked reconstruction and is intended
to be fine-tuned on your data; see :doc:`Training and Fine-Tuning <./fine_tuning>`.

Follow the model card links for input requirements, training data, intended use, and license terms.
